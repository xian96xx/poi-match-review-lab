POI MATCH REVIEW LAB · OFFLINE DEMO

门店信息匹配复核台

把跨平台门店匹配拆成可解释的候选与人工判断。

本地运行 · 无地图接口
演示数据说明内置的所有门店、地点和平台均为原创虚构。匹配结果是待复核候选，分数不代表真实业务准确率。

01 / INPUT

准备数据

使用内置案例，或导入自己有权处理的两份 UTF-8 CSV。

每个文件最多 1 MiB、2000 行。数据只在当前页面内存中处理；关闭或刷新页面会清除未导出的复核结果。

02 / OVERVIEW

匹配概览

每条参考记录计一次，匹配分类不等于正确率。

加载数据后显示统计。

03 / REVIEW

逐条复核

模糊匹配、冲突及多候选都需人工判断。确认或退回前请写原因。

这里会展示参考记录、候选和评分依据。
